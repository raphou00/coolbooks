# 📚 Coolbooks

> Generate AI books for kids in under 2 minutes

## 📱 Features

- Describe your child's look with name
- Choose art style (cartoon, comics, anime, watercolor)
- Enter prompt for the story
- Receive the book in PDF format to your email

## 🛠 Tech Stack

- **Next.js**
- **AWS**
- **TypeScript / JavaScript**
- **Nano Banana**
- **GPT 5.2**

## 🚀 Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/raphou00/coolbooks.git
cd coolbooks
```

### 2️⃣ Install dependencies

```bash
npm install
# or
bun install
```

### 3️⃣ Start the Expo server

```bash
npm run dev
# or
bun run dev
```

## 🧠 Technical Highlights

- State management using React hooks
- Local persistence with AsyncStorage
- Component-based architecture
- Clean folder structure
- Mobile-first responsive layout
